# catalog: community scripts

The Pine Script indicators and strategies under Indicators: Editors' picks, Top, Trending and Marketplace.
Each one was checked with AskCharts' own Pine interpreter before it was listed.

Only scripts whose authors gave them an open licence are here: 21 scripts, under GPL-3.0, MPL-2.0 or MIT.
Each keeps its own licence, named in `library/manifest.json` (which also says where it came from and who
wrote it), and the licence files sit beside the scripts in `library/`: the GPL-3.0 text for everget's
scripts, Geraked's MIT licence, and the MPL-2.0 text for Alorse's (whose files also say so in their header).

- `data/catalog.sqlite`: what the menus read.
- `library/`: the same scripts as files, at their original paths, with the manifest.
- `picks.json`: the Editors' picks.
